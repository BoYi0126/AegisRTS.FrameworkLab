# Definition of Done

每個 Phase：

1. Compile 無 Error。
2. Console 無未處理 Exception。
3. Acceptance Criteria 完成。
4. Public API 有 docs。
5. 新核心邏輯有 tests。
6. 有 debug 方法。
7. 無世界觀硬編碼。
8. 無錯誤 asmdef dependency。
9. 不破壞既有 Sandbox。
10. 可清楚 Git review。

Framework 最終：兩種背景、攻城與守城、Save/Load、AI 完整循環、Package 可安裝到第二個 Unity project。
