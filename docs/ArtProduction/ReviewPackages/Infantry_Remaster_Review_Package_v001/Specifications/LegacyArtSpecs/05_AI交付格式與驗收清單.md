# AI 交付格式與驗收清單

## 1. 可直接複製的任務前言

```text
你正在替 Unity 6 URP 的俯視角 RTS 製作遊戲資產。1 Unity Unit = 1 公尺，Y 軸向上、Z 軸向前，樞紐在底面中心，匯入後 Scale 必須是 1,1,1。風格為東亞古代軍事語彙的風格化低多邊形 3D，但不綁定特定朝代或既有 IP。資產必須在 960×540、55° 俯角、60° FOV、31 m 相機距離下可由輪廓辨識。請嚴格依附上的單一資產規格，不要自行改變尺寸或增加未要求的內容。
```

## 2. L1 概念圖交付

交付：

- 2048×2048 PNG。
- 正面、左側、背面、3/4 俯視圖。
- 黑色剪影。
- 我方藍 `#4AA3D8` 與敵方紅 `#D94A45` 兩種換色。
- 尺寸標註與配色表。
- 無背景或中性灰背景、無文字亂碼、無浮水印。

L1 不代表已完成遊戲模型。概念圖通過後才開始 L2。

## 3. L2 遊戲模型交付

交付：

- FBX 或 GLB、原始製作檔、貼圖與材質說明。
- 正確公尺尺寸、Y-up、Z-forward、底面中心樞紐。
- Transform 已 Apply/Freeze。
- UV、LOD0、LOD1、陣營色材質區域。
- 三角面數、材質槽數、貼圖解析度報告。
- 960×540 與 1920×1080 Unity 預覽截圖。

## 4. L3 完整資產交付

除 L2 外，另交付：

- 骨架與個別動畫 clips。
- 指定 Socket 與 Anchor。
- LOD2 或清楚的效能替代方案。
- 簡單碰撞代理建議，不使用精細 Mesh Collider。
- 我方／敵方材質切換示範。
- Unity Prefab 或可重現的匯入設定紀錄。

## 5. AI 生成紀錄

每次生成都要附一份文字紀錄：

```text
Asset ID:
交付等級: L1 / L2 / L3
生成工具與版本:
模型或服務名稱:
完整提示詞:
Seed / Job ID:
生成日期:
人工修改工具與步驟:
使用的第三方素材:
商用授權狀態:
已知限制:
```

若工具無法確認商用授權，標記為 `Blocked - License Unverified`，不可進正式發行內容。

## 6. 收件驗收清單

- [ ] 檔名、版本與 Asset ID 正確。
- [ ] 尺寸在規格容許範圍內。
- [ ] 腳底／底面貼地，樞紐正確。
- [ ] Y-up、Z-forward，Scale 1,1,1。
- [ ] 沒有多餘相機、燈光、背景平面或隱藏模型。
- [ ] 沒有浮水印、商標、亂碼或既有 IP 元素。
- [ ] 三角面數、材質槽與貼圖預算合格。
- [ ] 陣營色可替換，四個方向可見。
- [ ] 黑色剪影可辨識兵種／建築類型。
- [ ] 960×540 預設 RTS 視角可辨識。
- [ ] 動畫 Root Motion 為 0，事件點正確。
- [ ] 沒有明顯穿模、腳滑、破面或 UV 接縫。
- [ ] 來源、提示詞與授權紀錄完整。

## 7. 退件條件

以下任一項直接退件：

- 只提供漂亮渲染圖，卻聲稱是可用 3D 資產。
- 模型尺寸與規格差異超過 10%，且未事前說明。
- 以 Scale Factor 100 或 0.01 才能在 Unity 看起來正常。
- 陣營色被烘焙，無法執行期替換。
- 使用來源不明模型、現有遊戲角色或品牌徽記。
- 角色腳底不在 Y=0、朝向錯誤、Root Motion 推動角色。
- 兵種只有臉或紋理不同，960×540 輪廓無法區分。
