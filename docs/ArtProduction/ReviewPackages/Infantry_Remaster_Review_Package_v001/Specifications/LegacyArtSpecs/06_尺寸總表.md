現有原型血條固定在 Y=2.35，是 Placeholder 實作。換入不同高度模型時，應改為讀取各 Prefab 的 `HealthBarAnchor`，不能要求所有資產硬長成同一高度。

## 4. 容許誤差

- 人體高度：±0.05 m。
- 武器：±0.10 m。
- 建築外包絡：±0.10 m。
- 任何超出尺寸的設計必須先提供 Graybox 比較圖並取得同意。
- 尺寸表優先於概念圖視覺估算。
