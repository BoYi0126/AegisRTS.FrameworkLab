# UI 美術規格：肖像、圖示與選取標記

## 1. 適用範圍

這份文件定義與單位／建築美術配套的 UI 圖像。它不改變 UI 排版程式；所有圖示都必須能在 960×540 的緊湊 HUD 使用。

## 2. 單位與建築肖像

- 原始輸出：512×512 PNG，透明背景。
- Unity 使用：依平台生成 128 或 256 sprite；不要直接為每個解析度畫不同版本。
- 構圖：3/4 視角，單位頭肩或兵種武器佔畫面 75–88%。
- 建築：主輪廓佔畫面 80–90%，入口朝向一致。
- 外圍保留 8% 安全邊距，不放文字、數字或框線。
- 肖像底色由 UI 動態上色；不可把藍／紅隊伍框烘焙進圖片。
- 指揮官、副官可使用面部差異；普通兵種仍以盔、盾、弓等輪廓為主。

命名：`UI_Portrait_<Asset>_v001.png`。

## 3. 指令與狀態圖示

- 原始尺寸：256×256 PNG 或 SVG；若 AI 只能生成 bitmap，交付 512×512 再人工簡化。
- Unity 顯示最低尺寸：24×24 px；常用 32×32、48×48、64×64。
- 主圖形至少佔 70%，線寬在 256 圖上至少 12 px。
- 最多使用 3 個明度層級與 1 個重點色；不得依賴細文字。
- 透明背景，圖形居中，四邊 10% padding。
- Disabled、Hover、Selected 由 UI Shader／色彩狀態產生，不輸出四套幾乎相同 PNG。

首批圖示：Move、Stop、Hold、Attack、Repair Gate、Capture Stronghold、Recruit、Unit Settings，以及堅守／普通／攻擊／反擊四種交戰模式。

## 4. 選取圈與地面標記

- 選取圈為程式控制的獨立 Mesh／Decal，不烘焙進單位。
- 角色圈直徑：一般 `0.9 m`、指揮官 `1.1 m`。
- 騎兵：`2.4×1.1 m` 橢圓；攻城兵器：`2.8×1.6 m`。
- 建築圈沿足跡外擴 0.25–0.35 m。
- 線寬在 960×540、Zoom 31 時至少 2 px；世界厚度建議 `0.05–0.08 m`。
- 我方選取使用 `#4AA3D8` 或 UI Accent `#F0C65A`；敵對目標使用 `#D94A45`；不可只靠色彩，敵對圈可加短缺口／尖角形狀。
- 地面 Move Marker 顯示 0.4–0.7 s；Attack Marker 可使用向內收縮紅圈；不可永久留在地面。

## 5. 血條與狀態標記

- 血條由程式繪製，單位模型只提供 `HealthBarAnchor`。
- 960×540 最小寬度：一般單位約 28–40 px；英雄 40–56 px；建築 60–100 px。
- 血條高度至少 4 px，建議 6–8 px；受損變色不可只用難辨的漸層。
- 交戰模式狀態圖示置於血條旁或指揮面板，不掛成巨大 3D 圖示遮住角色。
- 螢幕邊緣、上方 HUD 與下方 Command Dock 內的世界血條應隱藏或重新定位。

## 6. AI 圖示提示詞模板

```text
Create a clean flat RTS UI icon for <ACTION>, transparent background, square composition, readable at 24x24 pixels, bold silhouette occupying 70–80% of the canvas, at most three value groups, no text, letters, numbers, border, watermark, gradients, photorealism, or copyrighted symbols. Ancient East-Asian-inspired but world-neutral. Deliver 512x512 PNG plus a black silhouette preview.
```

- [ ] 選取圈尺寸對應 `06_尺寸總表.md`。
