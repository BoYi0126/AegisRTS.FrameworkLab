# 視覺規格：風格、材質與陣營色

## 1. 整體風格

- 風格化低多邊形 3D，形狀清楚、稜面乾淨、材質簡潔。
- 比例偏寫實但略微誇張：一般角色約 5–5.5 頭身，指揮官約 5.5–6 頭身。
- 手、頭盔、武器與肩部可放大 10–25%，以支援 RTS 遠距辨識。
- 東亞古代軍事語彙可使用札甲、布袍、木構、瓦頂、旗幟，但避免直接複製特定歷史人物或現有作品。
- 同一材質的大色塊優先，避免高頻花紋、過多鉚釘與細碎配件。

## 2. 形狀語言

- 指揮官：上寬下穩、披風或背旗形成明顯三角／倒梯形。
- 副官：比士兵精緻，但輪廓低於指揮官一階。
- 步兵：盾或長兵器形成厚實直立輪廓。
- 弓兵：彎弓、箭袋與較輕甲形成開放輪廓。
- 騎兵：長水平馬身搭配高位騎手，移動方向一眼可見。
- 攻城兵器：低重心、木輪、撞木／機械臂形成長方形機械輪廓。
- 主堡：屋頂與門樓形成視覺焦點；城牆則規律、低細節、可重複。

## 3. 陣營色

暫定基準色：

| 用途 | 色碼 | 說明 |
|---|---|---|
| 我方主色 | `#4AA3D8` | 與目前 UI Primary 一致 |
| 我方深色 | `#235D82` | 旗幟陰影、布料暗部 |
| 敵方主色 | `#D94A45` | 高辨識紅，避免過暗 |
| 敵方深色 | `#7F2928` | 陰影與要塞旗幟 |
| 中立主色 | `#C8A842` | 黃褐色，不與 UI Accent 完全混同 |
| UI Accent | `#F0C65A` | 選取／重要提示，不作大面積陣營色 |

- 每個單位 15–25% 可見面積使用可替換陣營色。
- 建築 8–15% 可見面積使用旗幟、簷布、盾牌、燈籠或門楣等陣營色。
- 陣營色應從相機四個方向都可見；只在胸口放一小塊顏色不合格。
- 使用獨立材質槽或 `_TeamColor` 遮罩，不能把藍／紅直接烘焙成兩套不可換貼圖。
- 同一模型必須可切換我方、敵方、中立；不因換色增加一套網格。

## 4. 基礎材質

- 木材：中等明度暖棕，大塊紋理，避免照片級細木紋。
- 石材／夯土：中低彩度灰褐，大形塊與邊緣磨損即可。
- 金屬：深灰或暗鐵，Metallic 不超過必要部位；整身亮銀會在俯視角造成噪點。
- 布料：霧面，粗糙度高，顏色是陣營辨識主載體。
- 皮革：深棕，與木材用明度或粗糙度區分。
- 屋瓦：深藍灰或炭灰，避免純黑。

Unity 以 URP Lit 或 Simple Lit 為基準；角色亦可使用一致的風格化 Shader，但必須在 Windows Development Build 正常顯示。

## 5. 明度與輪廓

- 背景地面預期為中暗綠褐；角色不可整體同樣暗。
- 角色最亮與最暗區域應至少有清楚的三階明度：主體、陰影、重點。
- 武器與身體接觸處要有明度差，避免弓、槍、盾融入衣服。
- 轉成灰階後仍要看出兵種；如果只能靠紅藍色分辨兵種，視為失敗。
- 最細的永久幾何厚度：單位 `0.06 m`、建築 `0.10 m`；更細部分使用貼圖或移除。

## 6. 禁止項目

- 不要寫實血腥、斷肢或過度暴力表現。
- 不要 Q 版大頭到破壞軍事感；頭部不得超過角色總高 25%。
- 不要飄浮且無結構支撐的巨大裝飾。
- 不要在角色或建築上生成無意義文字、錯字、AI 亂碼。
- 不要使用現代軍事裝備、火器或科幻零件，除非後續世界觀文件另行授權。
- 不要將陰影或環境背景烘焙進 BaseColor。
- 不要浮水印、商標、現有 IP 徽章或不可追溯素材。

## 7. 概念圖標準

- 透明背景或 18% 中性灰背景。
- 同一角色需提供正面、左側、背面與 3/4 俯視圖，比例一致。
- 額外提供純黑剪影與我方藍／敵方紅換色比較。
- 圖上若有尺寸標線，使用公尺；不要用像素代表角色世界尺寸。
- 2048×2048 PNG 為概念圖最低建議輸出。
