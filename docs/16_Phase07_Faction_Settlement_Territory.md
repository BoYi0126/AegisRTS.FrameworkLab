# Phase 07 — Faction / Settlement / Territory

Faction：resources、settlements、armies、tech、diplomacy、AI profile。

Settlement：owner、population、garrison、resource、building、recruitment、defense、capture。

Territory：node/connection/owner/visibility/value。

Capture rule 可為 clear defenders、capture zone、destroy core、kill commander、mixed。

Acceptance：3 settlements 可改 owner，Faction territory 自動更新。
