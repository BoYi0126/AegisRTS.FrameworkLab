# Game Production 總覽

Framework 完成不代表正式商品完成。

正式遊戲需：World、Factions、Units、Heroes、Buildings/Economy Content、Maps、Scenarios/Campaign、Art/Animation/Audio、Balance、Tutorial、Polish/QA、Release。

Framework 名稱 `AegisRTS`；真正遊戲另命名，例如 `KingdomsOfHan`、`IronCrown`、`ArcaneSiege`。
