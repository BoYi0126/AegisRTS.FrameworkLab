# Phase 08 — Economy / Recruitment / Building / Technology

ResourceWallet 使用 ResourceId，不硬寫 Gold/Food。

Technology：DAG + modifier system。

Population/upkeep/supply 為 optional。

Acceptance：城池可產資源、建築、徵兵、研究；Fantasy 使用不同 resource 不改核心。
